# meetingVAR 本机实测项目

这是供首次实测使用的项目资料。会议主题是一次软件功能测试与发布排期。

## 监听重点

**测试**、**会议**、**部署**、**报告**、**发布**、**截止时间**。
英文语音也可使用 **meeting**、**test**、**project**、**report**、**deadline**。

## 可以在另一台设备或播放器中播放的句子

今天我们测试会议记录功能。请保存重要片段，结束后生成报告。
部署完成后还需要检查录音，发布的截止时间是周五。

Today we test the meeting project. Please save the important report.
The project deadline is Friday. We need to test the deployment before release.

## 验收任务

1. 播放经 Windows 默认扬声器或耳机输出的音频，确认终端出现转写。
2. 含监听重点的句子应触发 L1 或 L2；任意时刻也可按回车保存手动 VAR。
3. 两分钟结束后检查薄纪要、VAR 报告及 WAV、JPEG 原始证据。

系统声音环回不会额外采集本机麦克风；只对着电脑说话不能完成本测试。
