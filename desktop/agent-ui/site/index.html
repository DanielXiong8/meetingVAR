WHY EVIDENCE

别人帮你记下来，
meetingVAR 帮你证出来。

会议里最贵的不是没记笔记，是事后没人能证明当时到底说了什么。meetingVAR 不生成又一份摘要，它留下可回放、可校验、可追溯的片段。

01

不是摘要，是证据链

每个结论都带着说话人、时间戳、原话和屏幕帧。点开，就回到现场。

02

不是整场录音，是命中片段

只有内容与项目兴趣相关时才保留。30–90 秒一段，不把整场会议变成负担。

03

不是关键词搜索，是定位到秒

问一句「为什么改期」，它把决定、理由和上下文一起找出来，而不是丢给你十篇纪要。

EVIDENCE SKILLS

一个决定，三种证据

三种能力共用同一条证据链：台账告诉你谁改了什么，找回那一刻把原话递给你，证据包让第三方离线复验。

HOW IT WORKS

从一场会，到一份能复验的证据

不需要改变开会的习惯。它在你身后判断什么值得留下。

  1. 01

    建一个项目

    告诉它你在做什么：哪些人、哪些议题、哪些词与你有关。兴趣清单决定什么会被保留。

    项目记忆 · 兴趣清单
  2. 02

    只在相关时记录

    系统声音、麦克风、屏幕同时在场；内容命中项目兴趣，才留下一段可回放的证据。

    音频 + 屏幕帧 + 字幕
  3. 03

    生成证据包

    ZIP、manifest、每个文件的 SHA256。音频、字幕、屏幕帧和原话装在一起，离线也能验。

    ZIP + manifest + SHA256
  4. 04

    用一句话找回

    问「为什么改期」「谁答应过什么」，它给出 30–90 秒的片段，而不是整场录音。

LOCAL-FIRST

证据留在
你的电脑里。

会议内容默认不出本机。需要给别人时，你交出去的是一个可独立校验的证据包，而不是一个需要登录的账号。

先看常见问题
  • 01

    默认不上传

    系统声音、麦克风、屏幕帧和字幕都在本地处理；是否使用云端 ASR 由你配置。

  • 02

    只保留相关片段

    命中的内容进入证据池，未命中的不落盘。证据池属于项目，不属于某一场会议。

  • 03

    离线可校验

    SHA256 写在 manifest 里。断网、换电脑、交给第三方，都能重新算一遍。

  • 04

    随时可删除

    项目与衍生数据由你保管。删掉项目，证据池、索引和记忆一并移除。

FAQ

它不做什么，
和它做什么一样重要。

如果你在找一个「自动写纪要」的工具，它可能不是。如果你需要证明一个决定怎么发生的，继续看。

它会一直录音吗？

不会。它持续判断内容是否与项目兴趣相关，只有命中时才保留片段。证据池里是 30–90 秒的片段，不是整场会议的录音。

数据会上传到云端吗？

默认不上传。ASR 可以本地运行，也可以按你的配置走云端；会议内容、证据包和项目记忆默认留在本机。

拿到证据包的人怎么验证？

解压后按 manifest 逐个文件计算 SHA256，与清单里的值比对即可。全程离线，不需要安装 meetingVAR，也不需要信任生成方。

现在可以下载吗？

可以。最新 Windows 安装包发布在 GitHub Releases。网站只做产品说明和交互演示，不托管安装包，也不连接你的会议数据。

支持 macOS 或 Linux 吗？

当前只提供 Windows 10/11 桌面版，依赖 WebView2 与 Windows 的音频捕获能力。其他平台尚未验证。
