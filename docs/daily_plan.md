# meetingVAR 每日计划（v1 · 2026-09-30 排定）

> **怎么用这份计划**：里程碑（⭐ 行）定死不动；每日任务允许左右滑动（课程/主办方日程冲突就顺延），
> 但滑动超过两天要在周日联调节点上重排当周。每天收口物 = 当天结束时应存在的**可验证产物**，
> 不是"做了"而是"能演示/能跑通"。
>
> **时间投入**：国庆假期（10/1–10/8，具体调休以官方为准）每天 4–6h，是全赛程唯一大块窗口，骨架全压这里；
> 开学后每天底线 2h、周末半天。两人每晚 10 分钟文字同步（做了什么/卡什么/明天第一件事）。
>
> **分工**：A = 流水线工程（声音→结构化数据）；B = 产品与智能层（可看/可讲/可评）。定义见 plan.md §13。
>
> **纪律**：单个问题卡超过半天 → 直接走 spike README 里写的退路，不许死磕；范围冻结日（11/8）后只修不新增。
