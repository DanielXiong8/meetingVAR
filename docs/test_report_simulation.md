## 本轮修复

1. 回放及实时采集原先只重采样、不降混，双声道数据会被后续当成单声道，时长和内容均失真。统一转换为真正的单声道。
2. Session 用每秒采样数切每秒字节，导致环形缓冲时间戳翻倍；修复字节/采样单位、回溯边界精确裁剪、音频元数据与 WAV 时长不一致。
3. 五秒一喂的 replay 无法保留三秒尾巴；改为按采样点保留真实重叠，去除同一时刻相同句子的重复，并避免 finish 再处理纯尾巴。
4. ASR 每块先写临时 WAV 再删除，草稿音频仍实际落盘。改为向 FunASR 传归一化的内存 float32 波形，保留原有输出契约。
   接口依据：[FunASR 官方音频加载实现](https://github.com/modelscope/FunASR/blob/main/funasr/utils/load_utils.py)支持 NumPy 波形；本轮验证的是适配器契约，真实模型组合仍需回归。
5. 实时轮询改为按已消费音频的末尾推进游标；音频缓冲用采样时间轴，避免轮询墙钟跨过尚未消费的块。
6. `go/record` 在 finish 异常时仍释放采集和录屏；静音提前返回前也关闭高清补录。
7. 词表把普通四字中文标题当成章节编号过滤，导致“测序污染”未被抽取；手动 `#!keep` 行也曾被普通注释逻辑忽略。
8. 项目扫描剪枝排除虚拟环境、下载运行时和依赖目录，防止隔离环境被读成项目记忆。
9. 行动项不能把 S3、UMI 等监听技术词当成负责人；仅使用明确的人名名单作 @归属。
10. 可选 LLM 端点异常时降级而非阻断流程；无 JSON 返回时不再访问未初始化变量；兴趣文档无有效词汇时安全降级。
11. 修复测试本身的 HTTP socket 未关闭、人物名单写入真实 data，以及独立导入路径问题。

没有改动 Clip JSON 字段或 pool schema，没有引入云端音频依赖，没有改变“只转正命中音视频”的管线结构。

## 仍需如实保留的风险

- **隐私口径有差异**：静音且无片段时不创建产物文件；有正常转写、无命中时仍保存全文 `transcript.json` 和 `summary.json`。
  新测试分别验证两种情形。#27 的 G1“未命中任何文件零新增”文案比当前实现更严格；不能据静音审计宣称所有未命中会话均零落盘。
  本轮没有擅自删除薄纪要需要的全文，也没有把合成媒体结果包装成全进程/操作系统级写盘审计。
- **模型边界**：真实 FunASR/VAD/CAM++/标点模型组合、真实识别率、多人说话人归因、实际录屏、WASAPI 设备、GPU、高清补录均未在这台机器验证。
- **质量边界**：固定剧本与记忆只用于工程连通性；不是独立评测集，不计算或宣传真实 Precision/Recall/F1 提升。
  阈值回写仅验证机制，不能证明用户效用；原有启发式根据反例分数可能产生较大的单次阈值变化。
- **已有产品缺口**：厚纪要离线模式仍为填充上下文的 prompt 模板；真实 LLM 质量、RAG 上下文接入、全局人物缓存的项目隔离仍需专门验证/完善。
- **实时异常**：测试验证应用层正常关闭和 finish 异常关闭，不等价于断电/强杀后的数据处置，也不覆盖全部硬件初始化失败路径。

## 复现

从仓库根目录，使用 Python 3.10：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e . -r requirements-simulation.txt
python -m unittest discover -s tests -v
python -m meetingvar.simulation --output data/simulation
```

当前机器已建好 `.venv`，可以直接运行：

```powershell
.\.venv\Scripts\python.exe -m meetingvar.simulation --output data/simulation
```

每次产生独立的 `data/simulation/run_*/`：

- `result.json`：机器可读结果、模拟项和未验证项；
- `simulation.log`：实际执行过程；
- `data/reports/<session>/minutes.md`、`var_reports.md`：可查看的纪要；
- `data/pool/`、`data/clips/`：真实格式的片段 JSON、有效 WAV 和 JPEG；
- `project/meetingvar/`：归档、词表和校准状态。

以上媒体为合成测试数据，保留在本机且不入 Git；项目真实会议数据没有被复制或上传。
