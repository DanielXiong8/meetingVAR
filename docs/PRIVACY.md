# meetingVAR 隐私说明（产品草案）

生效日期：2026-10-20

meetingVAR 是本地优先的会议证据工具。本说明描述桌面版默认行为；企业部署可按组织策略关闭或调整。

## 默认不离开本机的数据

- 会议音频、屏幕帧、转写、纪要、项目记忆、对话、Agent Trace 和崩溃报告默认只写入本机 `data/`、项目 `meetingvar/` 和 `%APPDATA%\meetingVAR`。
- 项目文件读取只读取用户选择的目录；不会上传整盘或目录清单。
- 崩溃报告默认只写本机，且会移除 API Key、token、密码、Authorization 等敏感字段；上传遥测默认关闭，必须由用户显式开启并配置地址。

## 可能离开本机的数据

仅在用户主动配置并触发时：

- 自定义 OpenAI 兼容 API：提示词与相关上下文发送到用户填写的端点。
- 讯飞听写/转写：音频发送到用户配置的讯飞服务。
- 更新检查：向用户配置的更新清单地址发起请求。
- 遥测上传：用户开启后，发送脱敏崩溃报告到用户配置的地址。

## 用户控制

设置 → 商业与合规：

- 查看/激活/移除许可证；
- 关闭遥测上传；
- 打开本机崩溃报告目录；
- 查看各项目数据占用；
- 导出项目数据 ZIP；
- 输入 `DELETE` 后删除选中的对话/纪要/理解缓存/词表或全局片段。

删除操作不可撤销；删除前请先导出。

## 数据保留

桌面版不自动上传、不自动云备份。`data/retention_days` 配置保留为后续自动清理策略；当前由用户手动删除。

## 儿童与敏感场景

本产品面向工作与学习会议。录制他人声音/屏幕前，用户应取得适用法律和组织政策要求的同意。

## 联系

隐私问题请联系产品所有者；正式发布前需补充公司主体、地址、数据处理者、跨境传输和投诉渠道。
