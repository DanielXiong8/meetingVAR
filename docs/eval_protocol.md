## 0 · 术语与时间轴定义（实现严格对应）

| 名称 | 定义 | 出现位置 |
|---|---|---|
| 绝对时间戳 | live 采样时间轴由初始墙钟锚定后按采样数推进；replay=模拟基点+偏移 | Session 内部（ring / trigger_ts） |
| 会议相对秒 | 绝对时间戳 − 会话起点，`max(0, ·)` 截断 | pool JSON：`ts`、`audio.*_ts`、screens manifest |
| 环形缓冲格 | 连续音频按 1 秒分格（32000 字节），不足一秒尾块单独保留，按 600 秒时间窗淘汰；断流边界允许短格 | `pipeline._ring` |
| 回溯窗 | `[trigger − LOOKBACK, trigger]`，LOOKBACK 默认 300s，env `MEETINGVAR_LOOKBACK` | `pipeline._make_clip` |
| 片段音频物理窗口 | 窗内已到达的样本，精确裁剪两端；断流区间补静音以保留时间位置 | `data/clips/<clip_id>/<clip_id>.wav` |

**不变量**：① 格时间戳间隔 1.0s ⇔ 格内音频 32000 字节（不再是"0.5s 音频配 1.0s 标签"）；
② `RING_SECONDS ≥ LOOKBACK_SECONDS`（默认 600 ≥ 300，违反则该断言失败）；
③ 片段只含触发前已到达的数据，不含任何"未来"音频。

`audio.start_ts/end_ts` 对应保存 WAV 的物理起止，未包含转写句也不回退为零。
事件评估当前以媒体窗口作预测区间，默认 300 秒回溯容易合并相邻事件；这些测试验证匹配机制，不能作为真实触发 P/R。

## A 层 · 触发判断（决赛前目标，需剧本音频）

- **对象**：三层监听（L1/L2/L3）的命中判断
- **真值**：双标注者独立标注"应取证事件"（start/end + 描述），分歧协商定标
- **指标**：事件级 Precision / Recall / F1 / 每小时误触发数（原始 TP/FP/FN 计数必须保留）
- **事件定义与匹配规则**（`src/meetingvar/eval/matching.py`，2026-10-10 加固后）：
  - 预测事件 = 相邻命中片段按 `merge_gap`（默认 90s）合并，**输入乱序不影响结果**（内部排序）；
  - 匹配 = 时间重叠 > 0 **或** 中心偏差 ≤ `tol`（默认 45s，evaluate 已正确透传）；
  - 贪心一对一：按重叠降序归属（等值按索引，确定性）；一个真值最多一个预测，反之亦然；
  - 非法输入显式报错：负时间戳 / start > end / 真值缺字段 / `meeting_hours ≤ 0` → `ValueError`；
  - P/R/F1 分母为 0 时约定取 0.0（不虚报 1.0）。
  - **`merge_gap=90s` 与 `tol=45s` 是设计参数，不是真实数据校准出的最优值**：
    两个真实事件间隔 < 90s 且各有一个预测时会被并入同一预测事件（丢一个 TP）——
    正式评测必须同时报告这两个参数的敏感性。
- **工具**：`python -m meetingvar.eval.matching --pool <dir> --labels <json> --hours <时长>`
- **对照**：A1 剧本 vs 开放讨论；A2 已见术语 vs 未见表达（同义改写/代词/否定句/无热词的重要信息）；A3 干净 vs 噪声
- **纪律**：冻结词表/阈值/代码版本后跑测试集；不许看结果调参后再测同一集
- **状态**：⏳ 待剧本音频（人工 #4）。**当前没有任何真实 P/R 数值，不得对外引用**。

## B 层 · 证据保全（本层为"应用层持久化与缓冲语义"验收）

### B1 · 零落盘三级承诺（`tests/audit_zero_persistence.py` 真模型 + `tests/test_persistence_policy.py` 替身）

| 级别 | 场景 | 判定标准 | 实测 |
|---|---|---|---|
| G1a | 纯静音、零转写、零命中 | 产物目录零新增（**文件与目录**）+ 仓库工作树零变更 | ✅ |
| G1b | 正常语音、**成功转写**、零命中 | 同上；summary 报出内存转写句数但 `transcript_json is None` | ✅（真模型 7 句转写零落盘） |
| G1c | 有命中 | 新增仅限策略内产物，数量可枚举：`pool/<sid>/{transcript.json, summary.json, <clip>.json}` + `clips/<clip>/<clip>.wav`（有截屏再有 screens/；digest 后另有 `reports/<sid>/{minutes.md, var_reports.md}`） | ✅ |

策略解释（**文档明确，非遗漏**）：命中会话会把**全场转写文本**落盘（薄纪要"全场概要"的原料）；
重证据（音频/屏幕）仍只存命中窗。未命中会话连目录都不留——"没事故就什么都不落盘"。

**审计范围声明（重要）**：以上测试是**应用层持久化写入审计**——覆盖被测进程显式写入的
产物目录与仓库工作树；ASR 适配器已使用内存波形，不写草稿临时 WAV。**不覆盖**：其他依赖的 OS 临时写入、
注册表、页面文件、崩溃转储、其他进程行为。**不得据此宣称"操作系统级绝对零写盘"**；
需要该级别结论须上 Procmon 等系统级监控。

写盘点静态清点（全部路径，grep 可复核）：

| 路径 | 触发条件 | 说明 |
|---|---|---|
| `data/pool/<sid>/{transcript.json,summary.json,<clip>.json}` | 仅命中（G1c） | 会话产物 |
| `data/clips/<clip>/{<clip>.wav, screens/*.jpg, manifest.txt}` | 仅命中 | 片段媒体 |
| `data/hd/hd_*/{f_*.rgb, meta.json, hd_clip.mp4}` | 仅命中且 `--hd` | 高清补录 |
| `data/reports/<sid>/{minutes.md, var_reports.md}` | 仅命中且 digest | 纪要 |
| `data/terms.txt`、`data/persons.json` | 词表层（`terms --memory`） | 项目记忆派生，非会议内容 |
| `<项目>/meetingvar/minutes/*` | 仅命中且 `go` 归档 | 跨会话热词演化 |
| 系统临时目录 `*.wav` | 每次 ASR 调用 | 转写载体，`finally` 删除；崩溃时可能残留 |

### B2 · 回溯缓冲语义（`tests/test_ring_lookback.py`，确定性替身 30 组合）

- 覆盖：格时间戳/音频长度一致性；触发窗口上下界；连续性（无重复/缺口/越界）；容量与淘汰；
  早期触发（缓冲未满）；`trigger≈LOOKBACK` 边界（299/300/301）；保留上限边界（599/600/601）；
  长时运行（900s）；非整秒触发（305.5）；块长 0.5s / 5s / 3.7s（含残块）。
- 修复前实证缺陷：格为 0.5s 音频却标 1.0s（时间戳 2× 膨胀）→ replay 形状（5s 块）片段
  **在触发点前最多丢 2.5s 音频**（多个触发点全复现失败）；容量实际 3000s ≠ 文档 600s。
- 修复后：全部 30 组合通过；900s 长跑后缓冲恰为 600 格、旧数据正确淘汰、片段恰为最近 300s。

### B3 · HD 高清补录（`tests/test_hd_lifecycle.py`，可控屏幕替身 + ffprobe）

- 覆盖：启动条件（仅命中）、启动延迟、录满自动停、`stop()` 立即停、重复命中不重复启动、
  录满后再命中新目录、mss 缺失静默降级、**mp4 可解码且时长≈真实录制时长**、帧序列清理、
  `meta.json`（尺寸/帧数/实测帧率）落档。
- 修复前实证缺陷：帧以 raw RGB 写入 `*.png` → ffmpeg 实际解码失败，但代码不检查返回码，
  **谎报"合成完成"并删除帧序列（唯一的证据副本）**；mp4 为 0 字节/moov atom missing。
- 修复后：rawvideo 输入 + 返回码校验 + 失败保留帧；实测帧率合成（抓屏跟不上标称 30fps 时
  视频时长仍与真实时长一致）。
- **未验证（边界明确）**：真实显示器的 90s 端到端抓屏（含磁盘占用与掉帧曲线）。
  本机 2560×1600 实测：raw 帧 12.3MB/帧、抓取 ~19.7fps → 90s**标称** 30fps 需 2700 帧
  ≈ **33GB 临时空间**（合成成功后删除）。此为已知资源风险，缓解方案见 decision_log。

## 短句过滤策略（2026-10-10 固化，`tests/test_short_sentence_filter.py`）

单点过滤在 `pipeline._flush`（`len(text.strip()) < config.MIN_TEXT_CHARS`，默认 2），
因此同时决定三件事：① 是否进入转写 ② 是否参与触发 ③ 是否进证据与纪要。

| 语义类别 | 例 | 进入转写/触发/证据 |
|---|---|---|
| 单字确认 | 是 / 好 | ❌（默认阈值下丢弃） |
| 单字指令 | 停 | ❌（**已知代价**：有效单字应答也丢） |
| 双字否定 | 不是 / 别改 | ✅ |
| 双字指令 | 重测 | ✅（可触发） |
| 噪声碎片 | 嗯 / 空串 | ❌ |
| 正常长句 | 会后请确认… | ✅ |

阈值可逆：`MEETINGVAR_MIN_TEXT_CHARS=1` 可保留单字句（噪声一并进来）。
**边界**：单字热词在默认配置下不可能触发——若某项目需要以单字为热词，先调阈值再评测。

## 反泄漏纪律（每次评测前检查）

1. 词表/画像构建材料 ∌ 评测剧本内容
2. 评测集与开发集按整场划分（相邻片段不同组）
3. 阈值/模型/代码版本冻结记录在案（git SHA + config 快照）
4. 报告分项指标（按会议条件），不只报总体 F1

## 残余风险（2026-10-10 登记，含未验证项）

1. **live 采集游标**：已改为按消费 PCM 的结束位置推进，启动时处理已有缓冲，结束时冻结并排空尾块；
   确定性测试通过，但真实设备长跑、驱动阻塞和采样时钟漂移仍需观测。
2. **HD 临时空间**：见 B3（33GB/90s@1440p 量级）；缓解（降分辨率/降 fps/JPEG 编码）未实施。
3. **异常退出**：kill -9 时 HD 帧+meta 保留可再合成；pool/clips 已写文件为准；无崩溃演练。
4. **真实设备/实时性**：live 路径（WASAPI 环回、2fps 截屏缓冲）本轮未做端到端长跑。
