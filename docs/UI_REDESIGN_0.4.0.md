# 0.4.0 UI 重构：ZCode 式深色 Agent 工作区

日期：2026-10-20。目标：把 meetingVAR 从“功能卡片页”改成 ZCode 风格的桌面 Agent 工作区，同时保留全部会议采集、字幕、录屏、项目理解、Agent 和设置能力。

## 1. 结构

```text
┌──────────────┬─────────────────────────────────────────────┐
│ 侧栏 268px    │ 顶栏：前进/后退 · 页面标题 · 兴趣API/状态 · 设置 │
│              ├─────────────────────────────────────────────┤
│ 新建会议      │                                             │
│ 搜索          │   欢迎页 / Composer / 快捷动作               │
│ 自动化 Agent  │   或 项目 / 会议库 / Agent / 设置内容         │
│ 项目          │                                             │
│              │                                             │
│ 项目列表      │                                             │
│ 最近会议      │                                             │
│ 本机工作区    │                                             │
└──────────────┴─────────────────────────────────────────────┘
```

- 深色设计系统：`#181818` 主背景、`#1b1b1b` 侧栏、`#202020` 卡片、细边框、低对比文本。
- 欢迎页：中央品牌 mark、问候语、项目选择、Composer、快捷动作（开始会议 / 会议纪要 / 全库理解 / Agent 检索）。
- Composer：输入自然语言后直接进入 Agent 深度检索；空输入则打开会议控制台。
- 会议控制台默认收起，点击“新建会议/开始会议”或会议启动时展开；原有录制键、VAR、文件转写、实时字幕、屏幕预览、关注事项全部保留。
- 项目页：项目选择、材料摘要、全库理解、项目文件树。
- 会议库：搜索、按项目分组、场次详情、音频/视频/纪要回看。
- Agent 页：Agent 深度检索置顶；会前关注/会后事实双栏；项目记忆问答/检索。
- 设置：左侧二级导航（常规/外观/模型设置/使用统计/记忆与 Agent/关于）。
- 使用统计：真实读取项目内 `agent_run.jsonl` 的 LLM 调用，展示累计 Token、调用数、单日峰值、活跃天数、失败数、12 周热力图、每日趋势和模型占比。

## 2. 关键交互

| 动作 | 行为 |
|---|---|
| `Ctrl+N` / 新建会议 | 打开主页并展开会议控制台 |
| `Ctrl+K` / 搜索 | 打开会议库并聚焦搜索 |
| Composer 回车 | 把问题带入 Agent 深度检索 |
| 快捷“开始会议” | 打开控制台并触发开始会议 |
| 快捷“全库理解” | 打开项目页并滚动到全库理解卡片 |
| 快捷“Agent 检索” | 打开 Agent 页并聚焦输入 |
| 侧栏项目 | 切换项目并回主页 |
| 侧栏会议 | 打开会议库并显示该场详情 |
| 设置二级导航 | 切换常规/模型/使用统计等面板 |

## 3. 兼容性

- 所有原有 DOM ID 与事件处理保留；新增 `usage_stats` 桌面 API 和 UI 页面。
- 引擎/采集/保存链路未改动；UI 仍只通过 pywebview API 与引擎子进程交互。
- 窗口默认 1050×680 DIP，放在 `(0,0)`；在 Windows 150% DPI 下约 1564×992 物理像素，避免 1280×800 DIP 被放大到屏幕外。
- 若窗口过窄：侧栏自动折叠，项目/Agent 网格自动降为单列；设置内容可滚动。

## 4. 验证

- `node --check desktop/web/app.js` 通过。
- 完整 Python 测试（含新增 `usage_stats` 聚合测试）通过。
- 源码真实窗口：主页、项目、Agent 页可切换；Agent 页显示深度检索、会前关注、会后事实、记忆问答；使用统计页可加载（当前项目无 Agent trace 时显示 0 与“暂无数据”）。
- 打包后 `--selftest` 验证窗口+后端+前端 JS 桥。

## 5. 边界

- 使用统计只覆盖本机配置过的项目内的 Agent Trace；不统计其他机器/未运行项目。
- 现有会议证据、真实媒体、配置密钥仍按原策略保存；UI 不改变零落盘纪律。
- 浅色主题未实现；外观页目前说明深色主题。
- 外部连接器/MCP/RBAC/多租户仍是后续能力。
