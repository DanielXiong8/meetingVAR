## 4. 讯飞语音识别深挖（用户问题：它是怎么做的）

### 4.1 技术架构（公开资料归纳）

1. **流式 2-pass 二遍解码**：第一遍低延迟端到端模型出**实时中间结果**，第二遍用更大上下文+语言模型**重新解码出最终文本**——用户看到的"边说边出字、说完自动修正"就是这个。新一代「实时语音转写大模型版」基于星火大模型框架训练。
2. **个性化热词 = 解码期语言模型加权**：用户上传词条后构建**个性化词条语言模型**（词表/FST 加权），在解码阶段直接提升热词路径概率——**与我们"解码后纠错"是同题不同解**：它在解码时生效（能救同音字），我们的纠错在解码后（能救但受限于 ASR 给出的候选）。
3. **长音频转写（LFASR）**：深度全序列卷积神经网络，5 小时内音频整段解码，VAD 分段 + 标点 + ITN（数字规整）内置。
4. **说话人分离**：声纹特征聚类（diarization）按角色分段标注——与我们 CAM++ 同路线，工业级调优。
5. **前端**：降噪/回声消除/自动增益是其传统强项（硬件起家）。

### 4.2 产品形态与价格

- **讯飞开放平台 API**：语音听写（流式 WebAPI）、实时转写大模型版、LFASR 长音频转写；按调用量计费，新用户有免费额度。安静环境第三方横评**字错率 3.2%，API 横评领先**。
- **讯飞听见（iflyrec.com）**：C 端转写会员 + 企业定制 API/SaaS。
- **离线桌面**：Windows 离线**命令词** SDK、离线听写 SDK（合规文档公开），**授权制收费（装机数/授权数），无公开价目表**，全功能离线流式听写桌面级基本要走企业商务。
- **iFLYHOME OS**：嵌入式/硬件整机离线语音方案。

### 4.3 对我们的启示

- 讯飞强在**前端链路 + 解码期热词 + 2-pass 体验**；其离线桌面能力被授权模式锁在企业商务里——**"全功能、免费、本机离线、选择性取证"在消费级桌面正是空位**（我们差异化叙事成立）。
- 可抄的三件事：①2-pass 思路（见 §6 行动项）；②热词个性化（我们的纠错 v4 是"解码后"变体，方向一致）；③ITN 数字规整（"q三十"→"Q30"）。

## 5. 我们的架构现状（如实描述）

```
会议/系统声 → WASAPI 环回（48k×2ch）→ 转 16k 单声道
→ 1s 粒度内存环形缓冲（10min，不落盘）+ 30s 增量块（5s 尾重叠）
→ FunASR AutoModel（一次加载，全本地 GPU）：
    SenseVoiceSmall   非自回归 ASR（快，带语种/情感富标签）
    fsmn-vad          语音活动检测切分
    CAM++             说话人嵌入 → 按句 spk 标签
    punc_ct-transformer 标点恢复
→ 富标签剥离 → 术语纠错 v4（pypinyin 首尾音节锚定 + difflib 去数字）
→ L1 热词（5min 去抖）/ L2 TF-IDF 兴趣（jieba 双侧分词）/ L3 手动热键
→ 命中转正：回溯 120s 音频 + 2fps JPEG 截屏 → 片段池（Clip JSON）
→ digest：薄纪要（结构化/LLM 可选）+ 厚纪要 VAR 报告
```

**与讯飞逐项对比**：

| 维度 | 讯飞 | meetingVAR 现状 | 差距评估 |
|---|---|---|---|
| 流式粒度 | 字级（2-pass） | 30s 块级（块尾出结果） | **最大体验差距**；现场演示时转写是"一阵一阵"的 |
| 热词 | 解码期语言模型加权 | 解码后纠错 v4（funasr 热词参数实测无效） | 可用但天花板低；近音错写已闭环 |
| ITN 数字规整 | 内置 | 无（"Q30"→"q三十"） | 纠错模块已知局限 |
| 说话人分离 | 工业级 | CAM++ 本地可用，重叠段弱 | 剧本音频（干净多人）下够用 |
| 降噪前端 | 强 | 无 | 依赖播放源质量 |
| 离线 | 离线 SDK 授权收费/命令词为主 | **全功能全本地免费** | **我们的优势位** |
| 隐私 | 云端版数据出域；私有化要商务 | 数据不出机 | 我们的优势位 |
| 公开口碑基准 | 安静环境 CER 3.2%（API 横评领先） | SenseVoice 中文优于 Whisper-Large-V2（arXiv 2502.18913）；FunASR 长音频基准胜 Whisper | 我们没有**自己实测的 CER 数字**——需要补 |

## 6. 行动项（由本调研产生）

1. **跑一次自己的 CER 基准**（本周可做）：AISHELL-1 测试集 / WenetSpeech 会议子集，本地 GPU 实测 SenseVoice vs SeACo/Paraformer 的字错率——PPT 里放**自己测的数字**，比引用别人横评硬。
2. **低配版 2-pass**（低成本高收益）：30s 块实时出"草稿层"结果（已有），会后再对整段音频重转写一遍出"精修层"——离线成本≈0，对标讯飞 2-pass 体验，且厚纪要永远用精修层。
3. **热词正道再挖一次**：讯飞思路=解码期加权；在我们栈里对应 SeACo 独立调用（此前失败的调用方式值得按 funasr 源码再核一次版本 API），或评估开源 CER 最优的 **FireRedASR**（CER 2.89%）作为可切换引擎。
4. **ITN 轻量版**：中文数字→阿拉伯数字的规则表（三十→30、百分之三十五→35%），并进纠错模块。
5. **edu 获客策略**（抄通义）：清华学生场景 + 免费 + 本地隐私，正是校园冷启动配方。
