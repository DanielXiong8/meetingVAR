## 重新渲染

```bat

set TAG=60s
set PAGE=short.html
node render.mjs 30

:: 完整版
set TAG=
set PAGE=index.html
node render.mjs 30
```

```bat
:: 1. 起静态服务（渲染需要 http，字体和截图才加载得到）
cd competition\promo-video\build
D:\miniconda3\envs\meetingvar\python.exe -m http.server 8734 --bind 127.0.0.1

:: 2. 渲染（逐帧确定性，无 CSS 动画）
cd ..\_tools
node render.mjs 30

:: 只重做配乐
D:\miniconda3\envs\meetingvar\python.exe -I make_music.py ..\out\music.wav

:: 预览某个时间点
node preview.mjs 45 88 131

:: 全片联络表
node contact.mjs
```

第一帧依赖 `window.__ready`；`promo.js` 启动时会检查时间轴空隙，有空隙直接抛错（空隙会渲染成空白帧）。

## 关于参考片

`bar6CRErgC4`（Tool Finder）在这台机器上受 YouTube 反爬限制：`LOGIN_REQUIRED`，多个 player client 与浏览器内播放都取不到流。
因此风格分析基于：公开 oEmbed 元数据（标题/频道）、官方缩略图、以及页面里解析出的 8 章时间戳与简介。
**参考片的缩略图在分析结束后已删除**，没有留在仓库里，也没有进入成片。

PO Token 服务（`_tools/potserver`，192 MB）是为绕过反爬从源码编译的，实测**无效**——YouTube 封的是出口 IP，不是客户端特征。
保留它只是因为换到非机房节点后可以直接复用：`cd _tools/potserver/server && node build/main.js --port 4416`。
如果之后要更精确地逐镜对齐，需要你自己把 mp4 放进 `ref/`（该目录不提交）。
